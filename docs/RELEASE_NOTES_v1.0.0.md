## Highlights of Release v1.0.0

The `v1.0.0` milestone represents the first production-ready baseline of the **Student Management System** developed under the **GitHub Collaborative Software Development** curriculum.

### Key Capabilities Included:
- **Comprehensive Student Management:** Full CRUD lifecycle for student records (search, filter, sort, modal add/edit/delete, and profile views).
- **Academic Reporting & Analytics:** Live department distribution charts, admission timelines, and CSV export functionality.
- **GitHub Collaborative Workspace Simulation:** Embedded dashboards for GitHub issues, branch tracking, code reviews, and release notes.
- **Engineering Team Management:** Collaborator directory with profile management, institutional email contacts, and role governance.
- **Orange & White Design System:** Clean, modern interface styled in warm orange and crisp white without dark blue or distraction elements.
- **Windows One-Click Launchers:** `start.bat`, `run.bat`, and `test.bat` for seamless local setup.
